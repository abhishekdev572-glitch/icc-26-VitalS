# VitalSense Pressure Risk ML Model

This folder contains the trained `pressure_risk_mlp` model in multiple formats for deployment across the VitalSense system.

---

## Model Files

| File | Format | Purpose |
|------|--------|---------|
| `pressure_risk_mlp.pt` | PyTorch | Training / fine-tuning / research |
| `pressure_risk_mlp.onnx` | ONNX | Cross-platform inference (Python, C++, etc.) |
| `pressure_risk_mlp.tflite` | TensorFlow Lite | **EFR32xG26 deployment** (TFLite Micro) |
| `onnx_test_report.json` | JSON | ONNX vs PyTorch parity verification |
| `onnx_test_predictions.csv` | CSV | Sample predictions for regression testing |

> **Deployed to EFR32xG26:** `pressure_risk_mlp.tflite` → compiled via Silicon Labs AI/ML SDK → `autogen/pressure_risk_mlp_generated.hpp`

## Model Specification

### Architecture
```
Input (12) → Dense(16, ReLU) → Dense(8, ReLU) → Dense(4, Sigmoid)
```
- **Parameters:** 380
- **Framework:** PyTorch → ONNX → TFLite

### Inputs (12 features, fixed order)

| Index | Feature | Description | Range |
|-------|---------|-------------|-------|
| 0 | `position_CENTER` | One-hot posture | {0, 1} |
| 1 | `position_LEFT` | One-hot posture | {0, 1} |
| 2 | `position_RIGHT` | One-hot posture | {0, 1} |
| 3 | `log_duration_normalized` | `log1p(duration_sec) / log1p(7200)` | [0, 1] |
| 4 | `head_load` | Normalized pressure (ADC→load) | [0, 1] |
| 5 | `shoulders_load` | Normalized pressure | [0, 1] |
| 6 | `hips_load` | Normalized pressure | [0, 1] |
| 7 | `heels_load` | Normalized pressure | [0, 1] |
| 8 | `head_exposure_scaled` | Cumulative exposure (pressure × time) | [0, 1] |
| 9 | `shoulders_exposure_scaled` | Cumulative exposure | [0, 1] |
| 10 | `hips_exposure_scaled` | Cumulative exposure | [0, 1] |
| 11 | `heels_exposure_scaled` | Cumulative exposure | [0, 1] |

> **Note:** The EFR32 firmware (`pressure_risk_ml_xg26.h`) exposes a simplified C API taking only 5 inputs: `position`, `duration_sec`, `head_adc`, `shoulders_adc`, `hips_adc`, `heels_adc`. The wrapper computes log-duration, load normalization, and exposure scaling internally before calling the TFLite Micro model.

### Outputs (4)

| Index | Output | Description | Range |
|-------|--------|-------------|-------|
| 0 | `head_risk_score_0_to_1` | Risk probability | [0, 1] |
| 1 | `shoulders_risk_score_0_to_1` | Risk probability | [0, 1] |
| 2 | `hips_risk_score_0_to_1` | Risk probability | [0, 1] |
| 3 | `heels_risk_score_0_to_1` | Risk probability | [0, 1] |

**Firmware scales to 0–100** for BLE transmission.

## Teacher Model (Synthetic Labels)

Training labels generated by a physics-inspired risk function:

```
risk_zone = risk_gain * (pressure^pressure_exponent) * log1p(duration / reference_duration)
risk_zone = max(risk_zone, relief_floor)
```

| Parameter | Value |
|-----------|-------|
| `reference_duration_seconds` | 7200 (2 hours) |
| `relief_floor` | 0.1 |
| `pressure_exponent` | 1.5 |
| `risk_gain` | 1.5 |
| `low_medium_threshold` | 35.0 |
| `medium_high_threshold` | 70.0 |

### Posture Load Means (from recording)

| Posture | Head | Shoulders | Hips | Heels |

| LEFT | 0.831 | 0.253 | 0.925 | 0.247 |
| RIGHT | 0.543 | 0.890 | 0.251 | 0.431 |

## ADC Calibration (q05 / q95 per zone)

Used for ADC → load normalization:

| Zone | q05 (low load) | q95 (high load) |
|------|----------------|-----------------|
| Head | 3119 | 3932 |
| Shoulders | 3537 | 3994 |
| Hips | 3007 | 3909 |
| Heels | 3222 | 4021 |

```
load = clip((adc - q05) / (q95 - q05), 0, 1)
```

## Silicon Labs SML Setup & Model Conversion for EFR32xG26

### 1. Start WSL / Linux

On Windows, first open PowerShell/CMD and run:
```bash
wsl
```

Then inside WSL/Linux:
```bash
cd ~
```

### 2. Basic Packages

```bash
sudo apt update
sudo apt install -y \
    wget \
    unzip \
    ca-certificates \
    build-essential \
    python3 \
    python3-pip
```

### 3. Check if Silicon Labs SML is Already Installed

```bash
find "$HOME/.silabs/slt/installs" \
    -type f \
    -name "sml" \
    -perm -111 \
    2>/dev/null
```

### 4. Add Existing SML Installation to PATH

This is the path used in our working VitalSense setup:
```bash
export PATH="$HOME/.silabs/slt/installs/archive/sml-cli:$PATH"
hash -r
```

### 5. Check SML

```bash
which sml
sml --version
sml --help
```

For your existing installation, you should get something similar to:
```
/home/kiit/.silabs/slt/installs/archive/sml-cli/sml
```

### Make the PATH Permanent

Otherwise you need to run the export PATH=... command every time WSL is reopened:

```bash

source ~/.bashrc
which sml
sml --version
```

After that, every new WSL terminal should recognize `sml` directly.

## Converting / Rebuilding

### PyTorch → ONNX
```python
import torch
model = PressureRiskMLP()
model.load_state_dict(torch.load("pressure_risk_mlp.pt"))
model.eval()
dummy = torch.randn(1, 12)
torch.onnx.export(model, dummy, "pressure_risk_mlp.onnx",
                  input_names=["input"], output_names=["output"],
                  dynamic_axes={"input": {0: "batch"}, "output": {0: "batch"}},
                  opset_version=13)
```

### ONNX → TFLite
```bash
# Option 1: tf2onnx + tflite_convert
pip install tf2onnx tflite-support
python -m tf2onnx.convert --input pressure_risk_mlp.onnx --output pressure_risk_mlp_tf.onnx
tflite_convert --output_file pressure_risk_mlp.tflite --input_file pressure_risk_mlp_tf.onnx

# Option 2: Silicon Labs AI/ML SDK (recommended for EFR32)
# In Simplicity Studio: add "ML Model" component → select .tflite → auto-generates C++ wrapper
```

### Verify ONNX Parity
```bash
python -m onnxruntime.tools.run_onnx_model \
    pressure_risk_mlp.onnx --input_data test_input.npy
# Compare with PyTorch output → onnx_test_report.json
```

## EFR32xG26 Integration

The model is embedded via Silicon Labs **AI/ML SDK (TensorFlow Lite Micro)**:

1. Add `pressure_risk_mlp.tflite` to project via Simplicity Studio ML Model component
2. SDK auto-generates:
   - `autogen/pressure_risk_mlp_generated.hpp` (model weights as C array)
   - `autogen/sl_ml_model_pressure_risk_mlp.h` (TFLite Micro glue)
3. C wrapper `pressure_risk_ml_xg26.h/.cpp` exposes:
   ```c
   sl_status_t pressure_risk_ml_init(void);
   sl_status_t pressure_risk_ml_predict(
       pressure_position_t position,
       uint32_t duration_sec,
       uint16_t head_adc,
       uint16_t shoulders_adc,
       uint16_t hips_adc,
       uint16_t heels_adc,
       pressure_risk_result_t *result);
   ```
