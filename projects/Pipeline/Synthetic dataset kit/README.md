# VitalSense Synthetic Dataset Kit

This folder contains the **end-to-end pipeline** for generating synthetic pressure-risk datasets, training the prototype MLP, and running inference. It transforms paired Smart Belt (IMU) + Smart Bedsheet (FSR) recordings into a supervised learning problem for on-device edge AI.

## Teacher Risk Function (Synthetic Labels)

Labels are generated by a **physics-inspired risk function**, not clinical ground truth:

```python
# Effective load above relief floor
effective = clip((load - relief_floor) / (1.0 - relief_floor), 0, 1)

# Pressure-time dose
dose = effective^pressure_exponent * duration_sec / reference_duration_seconds

# Risk index 0–100
risk = 100 * (1 - exp(-risk_gain * dose))
```

| Parameter | Value | Meaning |
|-----------|-------|---------|
| `reference_duration_seconds` | 7200 (2 hrs) | Time constant for dose accumulation |
| `relief_floor` | 0.10 | Load below this contributes no risk |
| `pressure_exponent` | 1.50 | Nonlinear pressure weighting |
| `risk_gain` | 1.50 | Global scaling |
| `low_medium_threshold` | 35.0 | Risk level boundary |
| `medium_high_threshold` | 70.0 | Risk level boundary |

## Synthetic Subject Generation

| Setting | Value |
|---------|-------|
| `N_SYNTHETIC_SUBJECTS` | 120 |
| `ROWS_PER_SUBJECT` | 500 |
| **Total rows** | 60,000 |
| **Split** | 80/20 subject-wise (96/24 subjects) |

Each synthetic row:
1. Samples a **source stable row** matching the target posture
2. Applies **subject/global/mattress variation** (log-normal factors)
3. Adds **slow drift + measurement noise**
4. Converts load → ADC using calibrated q05/q95
5. Computes **teacher risk** for the sampled duration

---

## ADC Calibration

Uses **5th / 95th percentiles** from the full bedsheet recording per zone:

| Zone | q05 (low load) | q95 (high load) |
|------|----------------|-----------------|
| Head | 3119 | 3932 |
| Shoulders | 3537 | 3994 |
| Hips | 3007 | 3909 |
| Heels | 3222 | 4021 |

```
load = clip((adc - q05) / (q95 - q05), 0, 1)
```

## Model Architecture

```
Input (12) → Linear(16) → ReLU → Linear(8) → ReLU → Linear(4) → Sigmoid
```

| Layer | Size |
|-------|------|
| Input | 12 |
| Hidden 1 | 16 |
| Hidden 2 | 8 |
| Output | 4 (head, shoulders, hips, heels risk 0–1) |

**Parameters:** 380

### Input Features (fixed order)

| Index | Feature | Derivation |
|-------|---------|------------|
| 0–2 | `position_CENTER/LEFT/RIGHT` | One-hot |
| 3 | `log_duration_normalized` | `log1p(duration) / log1p(7200)` |
| 4–7 | `head/shoulders/hips/heels_load` | ADC → load via q05/q95 |
| 8–11 | `*_exposure_scaled` | `clip(effective^1.5 * duration / 7200, 0, 3) / 3` |

### Output

| Index | Zone | Range |
|-------|------|-------|
| 0 | Head | [0, 1] |
| 1 | Shoulders | [0, 1] |
| 2 | Hips | [0, 1] |
| 3 | Heels | [0, 1] |

## Running the Pipeline

### Prerequisites

```bash
pip install numpy pandas torch scikit-learn
```

### Generate Dataset + Train Model

```bash
cd "Synthetic dataset kit"
python build_pressure_risk_dataset.py
```

**Outputs:**
- `/mnt/data/synthetic_pressure_ulcer_risk_dataset.csv` (60k rows)
- `/mnt/data/pressure_risk_mlp_v2.pt` (PyTorch state dict)
- `/mnt/data/pressure_risk_model_metadata_v2.json` (full provenance)

> The script also prints the metadata JSON to stdout.

---

## Inference (Python API)

```python
from pressure_risk_inference import PressureRiskPredictor

predictor = PressureRiskPredictor(
    model_path=Path("pressure_risk_mlp_v2.pt"),
    metadata_path=Path("pressure_risk_model_metadata_v2.json")
)

result = predictor.predict(
    position="LEFT",
    duration_sec=3600,      # 1 hour
    adc_values=[3500, 3800, 3200, 3600]  # head, shoulders, hips, heels
)

print(result["highest_risk_body_part"])  # "HIPS"
print(result["zones"]["hips"]["risk_score"])  # 42.3
print(result["zones"]["hips"]["risk_level"])  # "MEDIUM"
```

### Inference (CLI)

```bash
python pressure_risk_inference.py \
    --position LEFT \
    --duration-sec 3600 \
    --head 3500 \
    --shoulders 3800 \
    --hips 3200 \
    --heels 3600
```
